# 随便 · 决策工具箱 (suibian)

> 把「不知道选啥」变成「一键搞定」的轻量决策小玩具。

仓库原本是空的，被当成了一块空白画布——于是有了这个纯前端的「随便」工具箱。名字叫 *suibian*（随便），功能也如其名：帮你做那些「都行、你定、我懒得想」的小决定。

## 功能

- **随机抽签** —— 输入一堆选项，让它随机帮你挑一个
- **幸运转盘** —— Canvas 绘制的旋转转盘，动画落点随机
- **抛硬币** —— 正 / 反，天注定
- **掷骰子** —— 支持 1～5 颗骰子，自动求和
- **🎲 TRPG 掷骰机** —— 桌游 / 跑团随手掷：d4 / d6 / d8 / d10 / d12 / d20 / d100 七种骰任选数量，支持 d20 优势 / 劣势（自动取高 / 取低）与加值调整，逐颗列出明细并给出合计；自动记录最近 50 次掷骰历史，纯前端零依赖、不联网
- **今天吃啥** —— 按口味（辣的 / 清淡 / 面食 / 外卖 / 随便）推荐
- **随便一句** —— 偶尔需要的一句不负责但管用的话
- **随机数** —— 给定范围，生成一个随机整数，专治选择困难
- **今日运势** —— 按日期出今日签，也可随手再摇一签，纯属娱乐
- **真心话大冒险** —— 聚会破冰 / 独自解闷，真心话、大冒险或随机来一个
- **扔飞镖** —— Canvas 靶盘，点哪扔哪，累计得分纯属手感
- **石头剪刀布** —— 和机器人出拳比手气，胜负平战绩本地保存
- **这事成吗** —— 给一件没谱的事算个成功率，配一句毒舌点评，纯属娱乐
- **灵感色卡** —— 配色没灵感时点一下，随机抽一张色卡并附对比色 / 邻近色，点色块即可复制
- **🌈 渐变工坊** —— 调一段好看的渐变，一键复制成 CSS 直接用：支持线性 / 径向 / 锥形、2–4 个色标、24 款精选配色、🎲 随机生成、收藏到本地随时取用，纯前端零依赖
- **🌈 配色方案生成器** —— 一键生成和谐配色方案：随机 / 类似色 / 互补色 / 分裂互补 / 三角色 / 单色阶六种规则；锁定喜欢的颜色、其余重新随机，点色块复制 HEX、一键复制成 CSS 变量、收藏到本地随时取用，纯前端零依赖
- **扭蛋机** —— 手痒了扭一下，随机掉出「锦鲤 / 灵感 / 治愈 / 好运 / 摆烂」五种小惊喜蛋，最近记录本地保存
- **🎫 刮刮乐** —— 鼠标 / 手指在卡片上刮开涂层，刮到一半自动开奖：终极大奖、金币、甜品、咖啡、好运或谢谢参与，加权随机、手气全凭天意；「再来一张」随时续命，最佳战绩本地留痕，纯前端零依赖、不联网

## 特性

- 纯前端、单文件（`index.html`），**零依赖、零构建**
- 完全离线可用，不联网、不收集任何数据
- 移动端友好，响应式布局
- **设置面板**：点顶部「⚙️ 设置」可开关音效、减弱动效、调整字号（标准/大）、切换紧凑布局、任选主题配色，全部本地记忆
- **全局音效**：点击按钮轻响、结果揭晓「叮」一声（WebAudio 合成，无需音频文件，可在设置里关闭）
- **一键清空本地存档**：在设置里清空抽签/扭蛋/石头剪刀布记录，主题与设置偏好保留
- 彩蛋：点 logo 切换整套主题配色（共 11 套，含一套浅色「纸感白」）；点「🎲 随便逛逛」或按 `G` 键，随机跳到一个工具逛逛
- **撒花庆祝**：抽签 / 转盘 / 扭蛋 / 抛硬币 / 石头剪刀布获胜 / 猜数字猜中等「赢」的时刻会撒一波彩带，开启「减弱动效」后自动关闭
- **分类导航**：215 个工具按「决策 / 运势 / 游戏 / 工具 / 效率 / 创作 / 生活」八大类排布，点分类胶囊一键筛选（每类带数量角标），选择记忆在本地、刷新不丢；与顶部搜索框自由组合，再多工具也不迷路
- **⌨️ 快捷命令面板**：按 `Ctrl` / `⌘` + `K` 随时唤出，模糊搜索全部工具（名称 + 关键词都认），↑↓ 选择、回车直达，空查询时顶部还会列出你「最近用过」的工具，键盘党狂喜
- **极光背景**：随主题色流动的极光光晕，开启「减弱动效」后自动静止
- **顶部实时时钟 + 时段问候**：页面顶部显示当前时间与「早上好 / 下午好 / 夜深了」等问候，每秒跳动，纯本地不联网
- **收藏 / 常用**：点导航按钮上的 ★ 把常用工具钉到顶部「常用」快捷栏，自动记忆，一键直达也能从「常用」里移除
- **今日宜忌**：首页每日按日期生成一行「今日宜 / 今日忌」，点「宜」直接跳到对应工具，纯属娱乐
- **成就墙 & 使用统计**：自动记录各工具使用次数（仅本地浏览器保存、不上传），累计解锁 356 枚成就徽章，随时在「成就墙」里查看进度与下一个目标
- **朋友圈文案**：选心情一键生成可发圈的文案，点结果即复制，社交发圈不再卡壳

## 本地运行

直接双击 `index.html` 用浏览器打开即可，无需任何服务器或安装步骤。

或者起一个本地静态服务器：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 在仓库 **Settings → Pages** 中，Source 选择 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`。
2. 保存后访问 `https://grrtyre.github.io/suibian/` 即可。
