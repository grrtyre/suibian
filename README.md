# 随便 · 决策工具箱 (suibian)

> 把「不知道选啥」变成「一键搞定」的轻量决策小玩具。

仓库原本是空的，被当成了一块空白画布——于是有了这个纯前端的「随便」工具箱。名字叫 *suibian*（随便），功能也如其名：帮你做那些「都行、你定、我懒得想」的小决定。

## 功能

- **随机抽签** —— 输入一堆选项，让它随机帮你挑一个
- **幸运转盘** —— Canvas 绘制的旋转转盘，动画落点随机
- **抛硬币** —— 正 / 反，天注定
- **掷骰子** —— 支持 1～5 颗骰子，自动求和
- **今天吃啥** —— 按口味（辣的 / 清淡 / 面食 / 外卖 / 随便）推荐
- **随便一句** —— 偶尔需要的一句不负责但管用的话
- **随机数** —— 给定范围，生成一个随机整数，专治选择困难
- **今日运势** —— 按日期出今日签，也可随手再摇一签，纯属娱乐
- **真心话大冒险** —— 聚会破冰 / 独自解闷，真心话、大冒险或随机来一个
- **扔飞镖** —— Canvas 靶盘，点哪扔哪，累计得分纯属手感
- **石头剪刀布** —— 和机器人出拳比手气，胜负平战绩本地保存
- **这事成吗** —— 给一件没谱的事算个成功率，配一句毒舌点评，纯属娱乐
- **灵感色卡** —— 配色没灵感时点一下，随机抽一张色卡并附对比色 / 邻近色，点色块即可复制
- **扭蛋机** —— 手痒了扭一下，随机掉出「锦鲤 / 灵感 / 治愈 / 好运 / 摆烂」五种小惊喜蛋，最近记录本地保存
- **神谕球** —— 心里装着个 yes / no 的问题？摇一摇，让神谕替你含糊其辞（上签 / 中签 / 下签）
- **随机排序** —— 一堆事分不清先后？丢进来，随机帮你排个执行顺序
- **倒计时** —— 专注一会儿或单纯掐个表，环形进度 + 暂停/重置 + 常用预设，到点轻响提醒，纯前端不联网
- **冷知识** —— 用不上的奇怪知识来一打，正经决策的间隙随便涨点见识，点结果可复制
- **决策天平** —— 两个选项放上去，CSS 动画天平歪向赢家，附一句毒舌点评，纯属娱乐
- **网名生成器** —— 随机拼一个可爱/中二的昵称，点结果即复制
- **分享卡片** —— 把任意一句话/结果做成好看的渐变卡片（5 种样式），一键下载成 PNG 图片，纯前端不联网
- **语音播报** —— 输入文字让浏览器用语音念出来（可调语速/音调，自动选中文嗓），不用联网，结果不顺耳就换个人念
- **随机分组** —— 把名单丢进来，随机分成 2～10 组，团建分队 / 分组作业 / 抽签都好用，结果可清空重分
- **猜数字** —— 心里想一个 1–100 的数让你猜，实时提示「大了 / 小了」，记次数，猜中即庆祝
- **密码生成器** —— 用浏览器加密随机源（`crypto.getRandomValues`）搓强密码：长度滑块、字符类型开关（大写 / 小写 / 数字 / 符号 / 排除易混字符 0O1lI）、强度条（按熵估算）、一键复制，纯前端不联网
- **塔罗牌** —— 静心想个问题，抽 1 张给自己一个提示，或抽 3 张看「过去 · 现在 · 未来」；22 张大阿尔卡纳随机翻转，正位 / 逆位各有解读，纯属娱乐
- **藏头诗** —— 输入 1–6 个字（名字 / 一句话），自动拼一首藏头小诗，点「复制」即可拿走，仅供娱乐

## 特性

- 纯前端、单文件（`index.html`），**零依赖、零构建**
- 完全离线可用，不联网、不收集任何数据
- 移动端友好，响应式布局
- **设置面板**：点顶部「⚙️ 设置」可开关音效、减弱动效、调整字号（标准/大）、切换紧凑布局、任选主题配色，全部本地记忆
- **全局音效**：点击按钮轻响、结果揭晓「叮」一声（WebAudio 合成，无需音频文件，可在设置里关闭）
- **一键清空本地存档**：在设置里清空抽签/扭蛋/石头剪刀布记录，主题与设置偏好保留
- 彩蛋：点 logo 切换整套主题配色（共 8 套）；点「🎲 随便逛逛」或按 `G` 键，随机跳到一个工具逛逛
- **撒花庆祝**：抽签 / 转盘 / 扭蛋 / 抛硬币 / 石头剪刀布获胜 / 猜数字猜中等「赢」的时刻会撒一波彩带，开启「减弱动效」后自动关闭
- **工具搜索**：顶部搜索框按名称 / 关键词实时过滤导航；按 `/` 聚焦、`?` 打开快捷键帮助、`1`–`9` 直达对应序号工具
- **极光背景**：随主题色流动的极光光晕，开启「减弱动效」后自动静止
- **顶部实时时钟 + 时段问候**：页面顶部显示当前时间与「早上好 / 下午好 / 夜深了」等问候，每秒跳动，纯本地不联网
- **收藏 / 常用**：点导航按钮上的 ★ 把常用工具钉到顶部「常用」快捷栏，自动记忆，一键直达也能从「常用」里移除
- **今日宜忌**：首页每日按日期生成一行「今日宜 / 今日忌」，点「宜」直接跳到对应工具，纯属娱乐
- **成就墙 & 使用统计**：自动记录各工具使用次数（仅本地浏览器保存、不上传），累计解锁 79 枚成就徽章，随时在「成就墙」里查看进度与下一个目标
- **朋友圈文案**：选心情一键生成可发圈的文案，点结果即复制，社交发圈不再卡壳
- **成语接龙**：前一个成语尾字接下一个首字，接到天荒地老，接不上自动换头继续玩，纯属文字游戏
- **心情日记**：选个表情、写一句，日积月累成一本只属于你的心情地图；本地保存、可逐条删除、可一键清空，纯私人不联网
- **专注音景**：实时合成的白噪音与环境音，六种声景一键播放、可调音量，专注 / 放松 / 助眠都好用，零音频文件不联网
- **记忆翻牌**：三档难度的表情配对小游戏，3D 翻牌动画 + 步数 / 用时统计 + 通关撒花，最佳成绩按难度本地记忆，锻炼记忆力也能解压
- **存档备份与恢复**：在设置里一键「导出存档」（下载 JSON 文件）或「导入存档」，换浏览器也不怕丢，所有本地数据（收藏 / 成就 / 记录 / 心情）尽在掌握
- **塔罗牌**：抽牌带翻转动画，22 张大阿尔卡纳随机正位 / 逆位，给你一个看问题的新角度
- **分享卡片**：把任意文字生成渐变卡片并可下载为 PNG，方便发到社交平台
- **名言收藏夹 & 习惯打卡**：把「随便一句」里喜欢的句子收进私人夹随时回味；给小目标每日打卡，攒连续天数并生成你的专属热力图，纯私人不联网
- **云养猫**：领养一只只属于你的「随便猫」，喂饭 / 玩耍 / 睡觉 / 洗澡 / 抚摸样样都行；状态会随真实时间自然变化（久了不理它，它会饿会脏会困），全部本地保存、关掉网页也还在，养到高等级还会触发升级撒花

## 本地运行

直接双击 `index.html` 用浏览器打开即可，无需任何服务器或安装步骤。

或者起一个本地静态服务器：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 在仓库 **Settings → Pages** 中，Source 选择 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`。
2. 保存后访问 `https://grrtyre.github.io/suibian/` 即可。
